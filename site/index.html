An open agentic website for the Worldwide Agentic Web

Find agentic sites. Check them. Then let one in.

Any site can publish agents that run in your browser. Before one gets your question, Gatehouse reads its public files, tests them against the spec, scans its instructions for tricks, and pins the exact version you approve. If that version changes, you are asked again.

Check a site

Paste a network URL: the folder that holds agent-manifest.json, then the network name.

Checking reads only that site's public agent files from its own origin. Nothing about you is sent: no key, cookie or chat text.

    For builders

    The same checks, for your own site, before judges or visitors try it.

    Command line

    Node 22 or newer. Exit code 1 when a site cannot be loaded.

    git clone https://github.com/zuhairhalawa/gatehouse
cd gatehouse
node cli/agentic-web-check.mjs https://your.site/your_network

    GitHub Action

    Check your published site on every push and pin its fingerprint.

    - uses: zuhairhalawa/gatehouse@main
  with:
    url: https://your.site/your_network
    strict: false

    Call Gatehouse from your site

    Add Gatehouse's network URL to an agent's tools and its origin to allowed_peers. Its directory desk answers "which site can help with this?" from the nightly snapshot.

    gatehouse

    Get listed

    Add your network URL to data/sources.json in a pull request, or to the official list. The nightly crawl picks up both.

    What a passport is not. It records what Gatehouse found in a site's public files on a given day. It does not prove a site is safe, who runs it, or what its own servers do.

    Built on the Worldwide Agentic Web MVP spec and its reference browser runtime (Apache-2.0). Gatehouse is Apache-2.0.
